# SDLC2 Governance

Process for LifeBuckets, introduced by the requested methodology setup.
Uncommitted documentation remains a proposal for Pablo's review.

## Rules

- [Document review](document-review.md): commit approval and attribution.
- [Branch lifecycle](branch-lifecycle.md): previous-sprint merge/cleanup and stable main promotion.
- [UI design review](ui-design-review.md): mockup and image evidence before UI implementation.
- [Workflow](sdlc2-workflow.md): planning, execution, evidence, and completion.
- [Component contracts](component-contracts.md): interfaces before implementation.
- [End-to-end gate](end-to-end-happy-path-gate.md): reproducible whole-system proof.
- [Environment separation](environment-separation.md): identities and deployment authority.

Root [agent rules](../../AGENTS.md) define repository-wide constraints.
If project documents conflict, identify the conflict and ask Pablo to resolve it before dependent work.
Explicit user instructions take precedence; record deliberate process exceptions and their scope.
