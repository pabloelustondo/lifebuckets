# Review and Release

Record independent review, human disposition, release readiness, accepted risks, and rollback plans.

Sprint closure integrates into dev and removes the sprint branches.
Promotion to main is separate and requires [real-user validation](../00-sdlc2-governance/branch-lifecycle.md).
Deployment alone does not satisfy either gate.

## Artifacts

Review reports and human decisions; a green build is not release authorization.

Start with the [review template](../templates/review.md).
