## Create a sprint package

0. Verify the previous sprint is merged into remote dev and its local/remote branches are removed; record evidence.
1. Create sprint-NNN-short-name/ and draft 01-sprint-plan.md using the [Plan template](../../templates/sprint-plan.md).
2. After Pablo commits the Plan and dependencies, draft 02-sprint-plan-tasks.md using the [Tasks template](../../templates/sprint-plan-tasks.md).
3. After the Tasks commit and explicit implementation authorization, create the dedicated sprint branch from verified current dev.
4. Link the delivered-scope report and test evidence from Build and Test.
5. Link independent review and human disposition from Review and Release.
6. Link any authorized deployment and live results from Operational Reality.
7. Record Pablo's merge into dev and local/remote branch cleanup before starting the next sprint.
8. Preserve correction reports and superseded evidence with explicit relationships.

Register sprint path, goal, actual state, Plan/Tasks commits, and evidence links here.
A draft folder or a status label never authorizes implementation.
